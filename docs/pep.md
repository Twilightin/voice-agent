# 段階的説明の原則（汎用版 / progressive-explanation-principles）

> 元文書「チュートリアル作成の原則」からコードへの依存を剥がし、
> **「何かを段階的に、詰まらせずに説明する」全ての制作物**に使える形へ抽象化したもの。
> 原則 ID（A1, B2, D9 …）は元文書（v2）と対応を保っているので、両方を並べて使える。
> v2 の全原則（A1–A17, B1–B31, C1–C10, D1–D26, E1–E8）を収録。近い原則は1項に束ね、ID を併記した（例: B12 / B18 / B23）。
> 元文書にあった個別の題材・当事者・失敗の経緯は剥がし、どの題材にも当てはまる形だけを残している。

---

## §0 この文書の運用ルール

- **適用範囲**: 講義・教材・解説記事・業務マニュアル・オンボーディング資料・研究発表・手順書・コードのチュートリアル。要するに「順番に読ませて理解させる物」すべて。
- **1教訓は1か所にだけ書く。** 原則に ID を振り、失敗カタログ（§6）とセルフチェック（§7）は ID で参照する。同じ内容を二度書かない。
- **題材固有の事情はここに書かない。** 個別のファイル名・数値・事例は別紙（companion doc）に置く。この文書は題材を差し替えても成立する状態を保つ。
- 新しい教訓が出たら: ①該当する柱に原則を1つ追加 → ②失敗例を §6 に1〜3行（ID参照） → ③必要なら §7 に1項目。**この3手で終わり**（本文に重複追記しない）。

## §1 受け手プロファイル（着手前に必ず確認）

説明の厚さ（§4）は「その領域が受け手にとって既知か・初学者か」**だけ**で決まる。だからこの表が土台になる。

| 領域 | 状態（既知 / 学習済み / 学習中 / 初学者） | 更新日 |
|---|---|---|
| （領域名） | | |

- **共通の前提**を1行で書く（受け手とすでに共有している語彙・道具立て・思考の型）。
- 既知領域との**対応づけ**で説明されると理解が速い（→ D4）。
- 抽象度が高い領域は、**身近なたとえ**で「なぜその表し方をするのか」から始める（→ D5）。
- プロファイルは古びる。着手前に鮮度を確認する。

## §2 制作の型（ワークフロー）

1. **設計を先に相談 → 合意してから作る。** 範囲・段数の上限・題材を決め、文書に残す（超えそうなら分割を提案）。
2. **番号順の段に分ける。** 番号＝作る順＝学ぶ順＝並べたときの順、を一致させる。
3. **実際に確かめる。** 「そうなるはず」で出さない。観測・試行・実行の**生の結果を記録に残す**。
4. 本文中の具体値は、その記録から引用する（→ C1）。
5. 受け手が**自分の手で再現できる形**（手順・問い・演習）を各段に添える。
6. 最後に「**学習版 → 実運用版**」を提示する（→ §5）。
7. 納品前にセルフチェック（§7）を全項目通す。

## §3 コア原則 — 5つの柱

すべての細則は、次の5つの柱のどれかの具体化にすぎない。迷ったら柱に戻る。

| 柱 | 一言 |
|---|---|
| **A 最小差分で積む** | 最小の成立形から、1段＝1概念で積む。段間の差分は1か所だけ見えること。 |
| **B 具体値で示す** | 抽象語で終わらせない。代表1件の実値から始め、並ぶ値・全項・出所は省略しない。before→after / 表 / 逐次トレース / 図。 |
| **C 実測に忠実** | 具体値は観測から引用。「原理的にできること」と「今回実際に起きたこと」を混ぜない。 |
| **D 黒箱を開ける** | 未説明の語・記号・名前・略記をゼロにする。 |
| **E 導出を教える** | 「何が要るか（枠）」でなく「どう思いつくか（論理）」に答える。 |

---

### 柱A: 最小差分で積む

**A1 — 一段一概念。** いきなり完成形を見せない。完成形は「難しさの塊」。まず**動く最小形**、そこから一段ずつ足す。各段は単独で成立すること。

**A2 — 骨組み固定・変更は1か所・新規に印。** 段をまたいで同じ骨組み（構成・見出し・語彙・主人公）を保ち、変えるのは1か所だけ。追加箇所に `NEW` 印。段Nと段N+1を並べたとき「**増えた1つ**」だけが見えること（作り直すと段階の意味が消える）。

**A3 — 一段は自己完結。** 理解のために他の章・他のファイルへ飛ばせない。必要なものを同じ視野の中に縦に並べ、上から下に読める形にする。※すでに既知の外部資源への参照は可。

**A4 — ギャップ駆動：「無い版 → 有る版」。** ある要素が「不完全→成立」を分ける鍵なら、①まずそれを**外した版で観測可能な失敗**を見せ、②その1つだけを足して直す。
判断基準＝「外すと**目に見える破綻**が出るか」。まとめて入れると、その要素は「最初からある呪文」に見えて何を・なぜが伝わらない。

**A5 — 正常系が先、例外は後。** まずハッピーパス。例外処理・網羅・特殊ケースは最後に足し、「**なぜ最後なのか**」も説明する。深い入れ子より、早期脱出でフラットにする形を先に教える。

**A6 — 80/20。** よく使うコア2割に集中し、残り8割は後回し。※これは**扱う範囲**の話。扱うと決めた物の説明は100%（未説明ゼロ → 柱D）。両立する。

**A7 — 各段に「予測してから確認」の問いを1つ。** 先を見る前に結果を予測させる1問を置き、答えは段末の実測で確認できるようにする（読むだけを、当てに行く読みに変える）。

**A8 — 全体を「要素 × 段」マトリクスで俯瞰させる。** A2 が各段の局所差分（増えた1つ）なら、A8 はシリーズ全体の大局。行＝段、列＝要素、セル＝ ◎（その段の新規）／●（持ち越し・合体）／空欄（無し）。

```
| 段 \ 要素 | A | B | C | … |
| 段0 素朴  | ◎ |   |   |   |   ← 単独デモ（◎1つ）
| 段1       | ● | ◎ |   |   |
| 段N 完成  | ● | ● | ● | … |   ← 勝ち残りを合体（●が横並び）
```

効果＝「素朴版は1個 → 完成版は**勝ち残った要素の束**」という累積が一目で分かる。どの要素を最終形に載せる／外すかは理由を1行添える（→ C2）。

**A9 — 範囲＝「題材が要る物」＋「その分野の共通語彙」の和集合。** 題材（北極星）は深さの上限を決めるが、採用の唯一の基準にしない。題材が使わなくても、**その分野の入門1ページ目に必ず出る語彙**（知らないと他人の文書が読めない2割）は入れる。ゴールが「自分で次を設計できる」である以上、これを欠くと題材しか扱えない人になる。
判定テスト＝「これを知らずに、その分野の標準的な入門文書の1ページ目を読めるか？」
※ A6 は「共通語彙の2割に絞る」、A9 は「その2割は題材の都合で削らない」。

**A10 — 本線は一本道、任意は分離。** 必修の背骨を1本の順路に固定し、番号＝作る順＝学ぶ順に揃える（並びが論理的なら A8 のマトリクスの◎は対角線に並ぶ）。「必須ではないが良い物」は本線に混ぜず、①段内オプション ②独立した小シリーズ（差し込み位置を明記） ③付録（読み物） の3か所に分離する。任意を必修の前提にしない（飛ばしても差分の鎖が切れない）。**外部シリーズの完走も前提にしない**：本線が必要とする概念は最小内蔵版を本線に持ち、外部は「深める先」のポインタに置く（途中で床が抜ける感覚を作らない）。

**A11 — 段間で結果が偶然一致しないようにする／一致なら役割差を明示する。** 段Nの目立つ結果が段N−1と同じだと、受け手は「前と同じ＝この段は無意味」と誤解する。対策は2つ: ①前段の題材を変えて数を違える ②どうしても一致するなら**役割の違いを表で明示**する。
判断基準＝「同じ結果を見た受け手が"なぜ同じか"を即答できるか」。

**A12 — 「全部に適用」依頼は全数列挙してから着手する。** 「すべての◯◯に X して」という一括依頼で、範囲語を自分の狭い定義で勝手に絞らない。手順: ①対象を**全数リストアップ**（1つずつでなく全体を先に把握）→ ②各対象に「適用 / 除外＋理由」を割り当てる → ③この網羅リストを提示してから作業する。除外するなら除外リストも見せ、"抜け"を即判定できるようにする。
判断基準＝「受け手が"で、残りは？"と1つずつ再依頼せずに済むか」。
※ A6/A9 が「範囲を絞る／絞りすぎない」話なのに対し、A12 は「絞ると決めた基準を明示して全数に機械適用する」実行段の話。

**A13 — 部品を積み終えたら「部品を鎖でつなぐ統合」を1本見せる（単体 → 結合）。** 別々の段で教えた部品を、入力が端から端まで流れる1本の鎖として実際に通して見せる。各リンクは既習の部品そのものを使い（作り直さない → A2）、入力→出力を1リンクずつ示す（→ B7）。簡略した所は明示する（→ C2）。
判断基準＝「部品を個別に学んだ受け手が"で、これらは一緒に何をする？"に、この1本で答えられるか」。
※ A8＝どの段がどの部品を持つかの静的な俯瞰／A13＝部品が協調して動く1回の動的トレース。

**A14 — 段のつなぎを「1本の物語」にする。** 各段の冒頭に「前段の到達点 →（まだ残る欠け）→ 今段の一手」を1〜2行のブリッジとして**1つだけ**置く。①「できたこと」と「まだできないこと（＝今段の動機）」を必ず対にする（A4 を段間に適用） ②物語の断片を本文に撒かず、この1か所に集約する ③統一モデル（D15）があれば、今段が全体のどこかを1語で指す。
判断基準＝「任意の段だけ読んだ受け手が"前段までに何ができ、なぜ今段が要るか"を冒頭2行で言えるか」。

**A15 — 途中追加は「枝番」で差し込み、採番の相談は最後に1回。** 番号順の構成（A10）にあとから段を足すとき、毎回「何番に入れる？」と受け手に尋ねない。隣の段を選び枝番（`2a`／`2b`）で差し込めば、既存の番号も範囲参照も壊れない。差し込んだら周辺（前段のブリッジ・全体マップ・俯瞰マトリクス）を1回で整える。通しの振り直しは全体が確定してから、一度だけ確認する。
判断基準＝「番号の相談で毎回手が止まらず、かつ最後まで番号が汚いまま放置されないか」。

**A16 — 並びは「データの流れ（実行順）」を最優先にし、各概念はデータがそこに達する位置で導入する。** 役割の似た概念をまとめて先に教え、それらをつなぐ共通部品を最後に1段で回す"概念順"にしない。実行順と教える順がずれると、隣り合う2段が直結しているように見え（実際は間に別の処理が挟まる）、「この2段はどうつながる？」で止まる。
① 番号＝作る順＝学ぶ順（A10）を、さらに＝データが流れる順まで縛る ② 概念は必要になった位置で初めて出す ③ 2回以上使う共通部品は、データが最初に通る所で教え、以降は「同じ物をもう一度」と指す。
判断基準＝「隣り合う段の"前段の出力→今段の入力"が、間に他の処理を挟まず本当に直結しているか」。

**A17 — 変更依頼は、下調べや道具づくりより先に「対象を実際に変えた1ブロック」を出す。** 一括の書き換え依頼で、読み込み・再計算・整形道具の作成に手番を使い切り、対象が1行も変わらないまま報告しない（受け手から見た進捗はゼロで、合意していない形式のまま道具だけが固まる）。①最初の手番で最小の1ブロックを対象に適用し、形式の合意は現物の差分で取る ②道具は、その1ブロックが通ってから残りへ機械適用するために作る ③報告するのは準備でなく対象の変化。
判断基準＝「この手番のあとに対象を開いた受け手が"変わった"と一目で言えるか」。
※ A12＝範囲を全数列挙する／A17＝列挙のあと、着手そのものを対象上で始める。

### 柱B: 具体値で示す（1件から始め、省略で済ませない）

> **柱Bの読み方:** 「具体1件」は**入口**であって**上限**ではない。説明は代表1件の具体値から始める（B1〜B10）が、並ぶ複数の値・下流で使う値・合計を作る全項は「1件＋あとは同様」で省かない（→ B12, B20, B28）。

**B1 — 状態を変える操作は「具体値で before → after」。** 「作る／更新する／変換する」の抽象語で終わらせない。実際の入力を1つ選び、**実行前の姿 → 実行後の姿**を並べる。

**B2 — 状態で挙動が変わる物は「状態表 ＋ 不変条件」。** 冪等性・分岐・表示の切り替えなど、状態によって起きることが変わる物は「**時点 × 状態 × 起きること**」の表で見せ、鉄則を1行添える（例:「消す条件＝出す条件を同じ状態変化に結ぶ」）。

**B3 — 繰り返し＋分岐は「1周ずつのトレース」。** 各周で「今の対象に対して各条件が真か偽か」を具体値で1周ずつ追う。**並び順**（データの順）と**分岐の振り分け**（処理の書き方）を混同させない。分岐に ①② の順序番号を付けない（付けるなら A/B 等、順序に見えないラベル）。

**B4 — 変換には「実データ → 結果」の対応図を1つ。** 説明文を増やすより、入ってくる生の値と、それが生む結果を1件並べる方が速い。「値がどう見えるか」は言葉でなく具体値で。

**B5 — 対象が入れ替わる状態は「時間軸で破綻 → 同一性で修正」。** 「済んだか？」のような真偽フラグは「**どれを**」を捨てるので、対象が複数あって入れ替わる場面で必ず破綻する。①隠れ前提（対象は複数・入れ替わる）を先に出す → ②時間軸（t1→t2→t3）でフラグが壊れる瞬間を見せる → ③一意の名札（id）で照合する版に直す（A4 の適用）。「なぜ中身でなく名札か」＝同一性の照合には一意の識別子が要る。

**B6 — 各部品の説明には「入力→出力」の実例を1組。** 役割の抽象文（「順位リストを返す」）で終わらせず、入力と出力を具体値で1組見せる。値は**実測を最優先**、実測前ならサンプルでよいが「例」と明示する（→ C1）。
**入力と出力は別の行に**（1行に詰め込まない）。長いものほど縦に割ると読める。

```
i/o 例:
  入力  {'A':6,'B':5,'C':5}（合計24で容量超）
  出力  {'A':6,'B':5,'C':2}（利益最小のCを削った）
```

**B7 — 提示する結果自体を「データの流れ」にする。** 最終結果の表を1つ出して終わりにしない。処理の順に1つずつ動かし、毎回「**入力（生）→ 中身の内訳（表）→ 出力（生）→ 一言**」を見せる。形が変わる様子（一覧→対応表→単一の数）も明示し、最後に「元 → 最終」の1行フロー図で締める。

```
一覧 ──集計──▶ {'A':6,'B':5,'C':2} ──所要──▶ 20 ──評価──▶ 84
```

判断基準＝「受け手が各段階の"出力の姿"を1つずつ絵にできるか」。中間物が見えないと「最終表が同じ＝前回と同じ」に見えて混乱する（→ A11）。

**B8 — 例の値は「ただの一例」と分かる普通の値にする。** 例に選ぶ値が、意味のある境界（上限・下限・ちょうど）や既定値、全要素が同じ値だと、受け手は「これは実際の入力？ それとも初期値／上限／仮置き？」と迷う。対策: ①主題でない入力は**バラけた中間値**にする（境界に張り付かせない） ②「これはただの一例」と一言添える。
※例外＝境界そのものを見せたい回は、むしろ境界に置いて「上限ちょうどの特別ケース」と明示する。
判断基準＝「その値を見た受け手が"特別な値ではなく、ただの一例"だと即分かるか」。

**B9 — 新概念の初出例は「意味のある題材（できれば直前の段の具体値）」で示す。** 無意味な記号・数字だけの例では、機構は分かっても「で、何の役に立つ？」で止まる。①まず意味のある題材で1例。できれば受け手が前段で扱った値を再利用し、新概念を「知っている物の一般化」として見せる ②抽象的な最小例は機構を見せる補助として併置してよい（機構→意味の順） ③**比喩も抽象で止めない**：比喩を出したら、その場で具体値の例に着地させ、「たとえのどこが本物と違うか」を1行添える。
判断基準＝「その例を見た受け手が"何のためにこれを学ぶか"を言えるか」。

**B10 — 規則・式は、適用する前に「手で解いた数値例」を1件置く。** 定義・記号だけ見せてすぐ実物（実装・手続き・帳票）に進まない。①規則 → ②実際の値を代入 → ③途中を1ステップずつ → ④答え、の解いた例を先に置く（規則は例から読み取る＝E1/E5 と同じ向き）。例の値は実物が出す値と一致させる（→ C1）。
判断基準＝「実物を見る前に、受け手がその規則を自分で1回手で解ける例を見たか」。

**B11 — 多次元の値は2次元の格子で示す（1行に平坦化しない）。** 表・行列・対応表の値を1行の並びのまま流さない。人は縦横の位置関係を1行から復元できない。行ごとに改行して格子にする。
判断基準＝「受け手が"第i行・第j列の値"を迷わず指させるか」。

**B12 / B18 / B23 — 並ぶ複数のもの（役割違いのN個・同じ規則に値を入れ替えるだけのN件・同じ操作を施すN個の入力）は「代表1件＋あとは同様」で済ませない。** 書き手には自明に見える「残り」こそ、受け手がまだ自信を持ってできない当の技能。
① 共通の規則を一度だけ示し「変わるのは値だけ」と明言する ② 各件を同じ手順で代入・展開して縦に並べる。全数が冗長なら**境界＋代表数件**に絞ってよいが、0件にはしない ③ **挙動が初めて変わる件**は必ず書き、一言注記する ④ **下流で値を使う件は、代表でなくても全部**展開する（「操作が同じ」と「値が同じ」は別） ⑤ 登場する固定値・係数は「どう作られたか」を添える（魔法の数を置かない）。
判断基準＝「並ぶ各件について、受け手が"この値はどこから・どの代入で出たか"を1件も欠けずに言えるか」。

**B13 — 構造・由来・流れは「文」でなく「図」で見せる。** どの値がどこから来たか・軸が何か・何がどう流れるかを散文で説明しない。①位置つき格子（結果と同じ位置に由来を書く） ②注釈つき分解図 ③矢印フロー図 ④時間とともに位置が変わる物は before/after のタイムライン。文で3行書く前に「図にできないか」と自問し、できるなら図を主・文を脇の1行にする。
判断基準＝「受け手がその図だけで"どの値がどこから来たか"を指させるか」。

**B14 — 版の違いは「各版まるごとの中身」を並べて目で差分させる。** 2つの版（before／after、案A／案B）の違いを、①機械的な差分記号の塊 ②「◯◯を変えた」の一言 ③変更履歴の見出し で代用しない。共有の出発点 → 各版のまるごと → 結果のまるごと、を並べる。機械的な差分は、全文を並べた"後"に従として添えるのはよい。
判断基準＝「受け手が2つを見比べて、記号や見出しを解読せずに違いを指させるか」。

**B15 — 入力の形で結果が分かれる仕組みは「代表ケースの早見表」で帰納させる。** 1例では、どの特徴が結果を決めたか切り分けられない。①共有の出発点を固定し、ケースごとに変えるのは1点だけ（→ A2） ②成功↔失敗の**境界をまたいで**並べ、各ケースは実際に試す（→ C1） ③最後に「何が起きたか｜なぜ｜結果」の早見表1枚で締める。
判断基準＝「受け手が新しい入力を見て、この表から結果を予測できるか」。

**B16 — 図は閲覧環境に依存させない。** 色・線・文字色を閲覧側の既定（明／暗テーマ、印刷、投影）任せにすると、ある環境で線や文字が背景に沈む。図が使う色はすべて自分で固定し（塗り・枠・文字・線・ラベル背景）、**想定される両方の環境で実際に表示して**確かめる（→ C1 の図版）。
判断基準＝「どの環境で開いても、線・矢印・ラベル・文字がすべて読めるか」。

**B17 — 「N個」と数を宣言したら、その場の列挙・図がNと一致しているか数え合わせる。** ずれる典型は、数は正典（詳細な段・凡例）から持ってきたのに、列挙は代表的な経路から書き、その経路を通らない項目が抜けるパターン。①数を書いた瞬間に指差し確認 ②数えるのは経路の数でなく、正典で定義した総数 ③要約は正典に突き合わせる（独自に数え直さない）。
判断基準＝「ラベルの数＝隣の列挙の項目数＝図の要素数、が三者一致しているか」。

**B19 — 「なぜ素朴案ではダメか」は、抽象表で述べず、具体1件の before/after で"衝突"を見せる。** 「Xが複数の役を兼ねている」のような欠陥を、役割を並べた表だけで示すと、受け手は"問題がある"と言われただけで体感できない。①代表を1件選ぶ（できれば既出の値） ②before＝素朴案で同じ値を複数の役に使い回し、区別できない衝突を具体的に指す ③after＝分けた版を同じ題材で並べる。
判断基準＝「受け手が"同じ値が衝突する before → 分かれる after"を目撃したか」。

**B20 / B21 / B25 — 値は「全項・出所・作られ方」まで辿れる形にする。** 受け手が"最後の一歩（この数は何か）"を自分で埋められると仮定しない。
① **和は全項を展開して合計に着地する**（0になる項も省かない。1項だけ変える前後比較でも、動かない項を残す）［B20］
② **式中の各数値に「どの名前つき値の何番目か」を添え、使う元の値は計算の直前に再掲する**（離れた定義に戻らせない）［B21］
③ **「〜後の値」のように操作名でラベルした中間値は、その操作を展開してから次の計算に使う**（操作名は結果の呼び名であって過程ではない）［B25］
判断基準＝「式の中の任意の数を指して"これは何の値？どこから？"と聞かれ、その場（スクロールせず）で答えられるか」。

**B22 / B26 / B27 — 流れの図は「本当の入力」から始め、集約を畳まず、介入点を名指す。**
① **起点**：通しの流れはその段に外から入ってくる値から始める。途中の中間値から書き出すと、それがどこから来たかが図の外に落ちる。最初の変換も1段として見せる［B22］
② **集約**：「1段」「ブロック」のような集約ラベルを1語の黒箱に畳まない。中のサブステップを実行順に全展開し、各段に「どの段で教えた部品か」の番号を付す。主線は縦に1本、分岐は横へ伸ばす［B26］
③ **介入**：既知の多段手順の1段だけを変える操作は、全段の図を再掲してその段を名指し（★）、介入前後で"変わらない段"が同じ値のままであることを両版で並べて裏づけ、「なぜその段でなければダメか」を1行添える［B27］
判断基準＝「図のどの段を指しても"何の操作か・どこで教えた部品か・入力はどれか"が分かり、図の外に落ちた由来がないか」。

**B24 — 段をまたぐ「出力→入力」の受け渡しは、実際の値で繋ぐ。** 段Nの出力が段N+1の入力になるなら、同じ値をそのまま再掲して繋ぐ。都合で簡単な代役の入力に差し替えるときは、必ず①その旨 ②本物はどこで繋がるか を明示する（黙って差し替えると「前段の出力はどこへ消えた？」で迷子になる）。教える順と実行の順が違うなら、本当の並び順を1枚で示す。
判断基準＝「任意の段の入力値を指して"前段のどの出力か／違うなら何の代役で、本物はどこで繋がるか"に答えられるか」。
※ A14＝段間の言葉のつながり／B24＝段間の値のつながり。

**B28 — 結果の表は導出の代わりにならない。** 実測値で埋まった表は完成して見えるが、並んでいるのは"結果"で"導出"は0件。受け手にできるのは信じることだけ。①代表1行は表のセルに着地するまで全段展開する ②下流で入力として使う行は、代表でなくても全展開する ③「実測」の但し書きは正しさの保証であって、展開不要の根拠ではない ④行数と展開の深さを取り違えない（N行の結果表＝N件の結果・0件の導出）。終盤ほど畳みたくなり、終盤ほど畳んではいけない。
判断基準＝「表の任意の1セルを、同じページの展開だけで再現できるか」。

**B29 — 多次元の計算は、展開を始める前に「形」を出す。** ①入力と出力の形（何×何）と、どの次元が消えて何が残るかを1行で ②演算対象は宣言した形のまま置く（見た目の都合で積み替えない） ③展開は形の単位で進める ④同じ演算が再登場したら同じ形式で再掲する。成分ごとの式に割ると、値は全部あるのに"向き"が消える。
判断基準＝「展開の1行目を読む前に、受け手が入力・出力の形と消える次元を言えるか」。

**B30 — 式・規則のすぐ下に、具体値の入った"絵"を毎回置く。** 2回目以降を「※上と同じ」で参照に落とさない。受け手はそのブロックだけを見て手を動かしており、戻らせた瞬間に流れが切れる。重複が気になるなら削るのは散文のほう。**言葉は畳む（→ §0 1教訓1か所）・絵は畳まない**。再掲だと伝えたいなら、絵を出したうえで「再掲」と添える。
判断基準＝「そのブロックだけを切り取って渡しても、前に戻らず手を動かせるか」。

**B31 — 記号・名前は1つの軸で揃える。** 同じ図・同じ段で「どこ側か（場所）」と「どの段か（工程）」のような2つの軸の名前を混ぜない。①軸を1つ決めて全記号に適用 ②経路が違う物は、値が一致しても同名にしない ③一致は隠さず「たまたま同じ」とその場に書く ④その段に出てこない名前は1行で否定する ⑤記号を導入したら「元 → 変換 → 結果」の対応を1行で添える。
判断基準＝「その段の名前を全部並べたとき、すべてが同じ質問に答えているか」。

### 柱C: 実測に忠実

**C1 — 具体値は観測記録から引用する。** 手で作った例を混ぜない。①実際にやって**生の結果を残す** → ②本文の値はそこから引用。記録に無い値を書くときは「実測でなく設計値／例」と明示する。

**C2 — 「できること」と「やっていること」を分ける。** 原理的にできる事と、この実例が実際に通った経路は違う。混ぜて「これは○○する」と書くと嘘になる。経路を1本ずつ辿り、「この入力はどこへ進み→何を出すか」を具体値で確かめてから書く。**過大に一般化しない。**

**C3 — 比べる前に「同じ軸か・別の軸か」を判定する。** 横並び比較は**同じものさし**に載る段だけ。途中で目的が変わる段は別軸で、同じ問いを当てると「答えが同じ＝差が無い」に見えて誤解を生む。
比較不能テスト＝「同じ問いに同じ答えが出るなら、ものさしが違う」。別軸は分け、価値が出る**別の問い・状況**で見せる。文書のセクションも軸ごとに割る。

**C4 — 「良し悪しの読み方」は 生データ → 理想の答え → 各段の実測 → ものさし の順。** いきなり各段の成果物を並べない。①実際に取れた素材 → ②理想の答え（採点基準）→ ③各段の実測（工程を分けて）→ ④差を指標で一言。良し悪しは**生データと理想の差から論理で導く**（印象で語らない）。

**C5 — 「▼ 読み方」の一般化は、全セルで検算してから言い切る。** 目立つ1例だけ見て「対角が最大」「右ほど増える」と法則化すると、他の行が反例のとき嘘になる。①言い切る前に全セルで反例が無いか確かめる ②反例があれば「〜しやすいが必ずではない」と幅を持たせ、反例と理由を1つ添える（反例は次の概念への入口になる）。
判断基準＝「その一文に、同じ表の中の反例が無いか」。

**C6 — 言葉で述べた性質は「ラベル」で終えず、混ぜ物のない指標で数値化する。** 「多義」「近い」等のラベルは説明ではない。①素朴な量に別の要因が混じる（交絡）なら、それを除いた指標で測る ②2つの指標が食い違うなら放置せず、なぜ食い違うか・各指標が何を語るかを1段ずつ和解させる ③ラベルの中身（構造的な正体）まで言う。
判断基準＝「その性質が、ラベルでなく"適切な指標の値＋なぜその値か"で説明され、指標の食い違いが矛盾のまま残っていないか」。

**C7 — 操作が作用する"単位"で説明する。** 例が合成物（文・案件・チーム）でも、操作が要素ごとに独立なら、その旨を明示する（「ここではまだ要素どうしは混ざらない」）。合成が実際に起きる段を指す。合成物全体の話として語ると「この段で結びつく」と誤解させる。
判断基準＝「受け手が"この段で要素どうしは混ざるのか"に正しく Yes/No を言えるか」。

**C8 — 版どうしを比べるときは「同じ段」で揃える。** 新版が旧版に工程を1枚足していると、最終結果どうしの差は「比べたい概念の差」と「足した工程の副作用」が分離できない。①比べたい概念が現れる同じ段の中間物どうしを選ぶ ②片方だけにある工程は「追加」と明示し、その効果は別に見せる。
判断基準＝「その差は比べている概念だけで説明でき、足した工程が原因の分がゼロか」。
※ C3＝同じ軸（ものさし）か／C8＝同じ段（工程の深さ）か。

**C9 — 提示した結果に現れた記号は、その場（初出）で1つ残らず解読する。** 「専用の段で説明するから」と先送りし、先に出た側で記号を宙に浮かせない。①結果を貼る前に、そこに出る記号を数え上げる（B17 の記号版） ②詳しい解説は正典1か所でよいが、先に出る側にも最低限の一言＋「詳細は §X」を添える ③段を挿入したら初出位置を測り直す。
判断基準＝「そのページだけを読む受け手に、未定義の記号が残らないか」。

**C10 — 同じ入力を共有する兄弟の段では、片方だけ"きれいな簡略"で入力の作り方を変えない。** 片方だけ前処理を1段抜くと、同じ対象が段ごとに別の値になる。簡略の旨を断っても（→ B24）、受け手に届くのは食い違う値そのもの。段をまたいで食い違いを生む簡略は捨て、本物の入力で揃える（迷ったら忠実側へ）。
判断基準＝「兄弟の段で、同じ対象の入力値が一致しているか」。

### 柱D: 黒箱を開ける

**D1 — 名前で済ませない（一語の術語は必ず開ける）。** 手法名・専門用語を「これで○○できる」で終わらせない（呪文になる）。受け手は中身を知らない前提で4手順:
① **よくある誤解を先に潰す**（特に「順番か・独立か」「何と何を混ぜるか」）
② 中で実際に起きる過程を段に分けて見せる
③ 具体値で1件トレースする（各段の入力→出力を実数で。実測に沿わせる）
④ 名前の一般論でなく「**この文脈が実際にする計算・手続き**」を書く（「A＝B」と決めつけない）
判断基準＝「"で、中で何が起きてるの？"と聞かれて実挙動で答えられるか」。

**D2 — 初出のパラメータは1つずつ。** 各項目に「何を指すか／実際の値／変えると何が変わるか」を添える。暗黙のもの・既定のものも省かない。
判断基準＝「この値を別の値にしたら何が変わるか、受け手が言えるか」。

**D3 — 曖昧な省略記法を使わない。** 「A/B」「〜等」「〜系」のような縮約は多義（両方か・どちらかか不明）で、実際の差を隠す。「AとBの両方」「Aだけ」「AまたはB」と言葉で開く。**短さより「読んで一通りにしか取れないこと」を優先。**

**D4 — 既知との対応表。** 新しい概念・記法は必ず受け手の既知（§1）に対応づける。表で。

**D5 — 「なぜその表し方か」を身近なたとえで先に。** 抽象は自明ではない。日常の比喩で理由を示してから抽象に入る。

**D6 — 慣用か学習用かを区別する。** そのやり方がその分野で「普通・慣用的」なのか、「学習用の簡略形」なのかを明示する（「これは実務でもこうなの？」に先に答える）。

**D7 — 概念の説明を実物の前に置く。** 実物（手続き・数式・帳票・コード）だけを並べない。番号付きの解説を交互に挟み、型は3点: ①**何者か**（既知との対応表＋図） ②**なぜ要るか**（無いと何に困るか） ③**どこまでやるか**（この段の箱の外）。紛らわしい語のペアは**定義表で先に固定**する。あわせて、段の名前は仕組み名でなく「**学ぶ概念名**」で付ける。

**D8 — 抽象化の層（包み紙）は「はしご」で導入する。** いきなり便利な上位の道具から始めない。**素手 → 標準的な道具 → 高水準の枠組み** の順に1段ずつ置き換え、各段で「前の段の何が困るか」を見せてから採用理由を1行で言う。A4（ギャップ駆動）を道具選択に適用した形。

**D9 — 繰り返しと入れ子を黒箱にしない。** 「採用された結果」だけでなく全過程を開く:
1. **全反復を表に** … 外側＝手番、内側＝各候補の全評価。採用に ★。**選ばれなかった候補の値を並べて初めて「なぜそれが選ばれたか」が分かる**（「なぜ最初がBか」→ B(+8) > A(+5) > C(+3) を全部見せる）。
2. **1回分の入れ子を分解** … 中で何が何を呼ぶかを ①②③④ と具体値で展開する。
3. **全手番を1表に畳んで縦比較させる** … 1手番だけ開いても「手番をまたいで何が変わったか」は見えない。全手番×全候補を1表にし、各行に**その手を左右した変数の実値**を併記する。採用が乗り換わる瞬間・止まる瞬間が「どの変数がどの値で頭打ち／失格になったか」で読める（別々の制約が別々の列に同時に見える）。

判断基準＝「"その中で何が何回起きたか"を1行ずつ追え、かつ手番をまたいで値を縦に比べられるか」。
※ 本体は綺麗なまま残し、可視化用に「同じ処理＋全記録版」を別に置くと両立する。

**D10 — 中身の説明は操作名でなく「しきい値で起きる結果」まで自然言語で。** 「小さい方を掛けて合計」のような**操作の羅列**で終えない。上限・しきい値・境界で**何が起きるか（結果）**を平文で書く:「上限に達したらそこで止まる → それ以上増やしても増えない（増分ゼロ＝頭打ち）」。この"結果"こそが後段の挙動を決めるのに、操作名だけだと受け手は自分でその効果を導けず詰まる。
書く順＝①各手順を番号付きの自然言語 → ②鍵になるしきい値の行に ★ を付けて結果を明記 → ③入出力例（→ B6）。
判断基準＝「入力を境界値（ちょうど／超過）にしたとき出力がどう変わるか、受け手が言えるか」。

**D11 — 途中で書き換わる「走査中の状態」は1反復ずつ開く。** 「これまでで最良のもの」を覚える箱は、値がその場で変わるので初学者の最難関。3点で開く:
① 箱の意味と初期値を明示（「これまでで一番◯◯なものを覚える箱。最初は空＝暫定王者なし」）
② 各反復の「**更新前 → 条件の真偽 → 更新後**」を表で1行ずつ
③ 初期値の慣用（「空を置く＝1個目は比較相手が無いので無条件採用」「1個目を暫定王者にする」）が同じ発想の別の置き方だと対応づける
判断基準＝「各反復の後にその箱が何になっているか、受け手が言えるか」。

**D12 — 「採用分だけ」の簡易トレース表には、出発点の行と乗り換え理由を注記する。** 紙幅の都合で採用結果だけを並べる表は2つの"段差"で混乱を生む: ①**入力そのものの行が無く**、1行目がいきなり「1手進んだ後」になる ②切り替わった行で**不採用候補が消える**ので「なぜここで乗り換えた？」が読めない。
対策（最小追加）: **手番0＝出発点の行を先頭に置く**／**切り替わる行にだけ**不採用候補を注記する（全行には付けない）。
判断基準＝「各行が"何から・何へ・なぜ"進んだか、出発点と不採用理由まで追えるか」。
※ D9＝全候補を開く完全表／D12＝採用分だけの簡易表に最小の注記を足す軽量版。粒度が違う。

**D13 — 規則・公式が主役の難概念は「素朴案を1つずつ潰す」導出で必然化する。** 公式を並べても「なぜ**この**形か」は伝わらない（公式は結論であって導出ではない）。①素朴案を順に出し、各案の失敗から欲しい条件を1つずつ立てる ②残った条件を満たす形として公式を最後に置き、各記号を①の直感に対応づける ③具体値で流して確かめる（→ B7）。
判断基準＝「受け手が"他の素朴案ではなく、なぜこの形か"を失敗の連鎖として言えるか」。
※ E3（部品は発明の1問で）の公式版。

**D14 — 各中間物には「値・式」だけでなく"意味"を1行添える。** 受け手が詰まるのは計算でなく「この量は結局何なのか」。①何を表すか ②なぜその操作がその意味を生むか ③具体値で1つ読む、の3つを揃える。量そのものだけでなく、その成分・軸・列見出しが未定義なら、何の軸かも言う。
判断基準＝「受け手が各中間物を"何を表すか"の一言で言えるか」。

**D15 — 独立した部品を1つに束ねる「統一モデル＋たとえ地図」を持つ。** 部品ごとのたとえ（D5）を各段に置くだけでは、たとえが乱立して森が見えない。①全体を貫く統一モデルを1つ用意する（厳密さより全体の流れが1枚で掴めることを優先し、不正確でよいと明示） ②個別の比喩はその中の一場面として接続し、段をまたいで同じアンカーを再利用する ③「概念 → ひとことのたとえ → モデル内の場所 → 段」の地図を1か所に置く ④各段のブリッジ（A14）からモデルの場所を1語で指す。
判断基準＝「受け手が"各部品が全体でどう協調するか"を1つの絵／物語で言えるか」。
※ A13＝計算の統合／A14＝読みの連続／D15＝イメージの統一。

**D16 — 「読む係」と「動かす係」を分ける。** 解説（たとえ・分解図・なぜ・導出・読み方の散文）は読み物の文書に集約し、実物（コード・手順書・テンプレート・帳票）には「それが何をするか」の最小注記と、解説への1行の誘導だけを残す。解説を実物に溜め込むと、肝心の実物が読めなくなる。
判断基準＝「実物を開いた受け手が、講義文に埋もれず"何をしているか"だけを追えるか」。

**D17 — 名前に数が入った概念（3者・2段階・k個…）は「なぜその数か」を開く。** ①その数が何を数えているかを名指す ②1つ少ない版がなぜ足りないか ③1つ多い版がなぜ不要か。
判断基準＝「受け手が"なぜ1つ少なくも多くもなくその数か"を1文で言えるか」。

**D18 — 非対称な操作（AにB ≠ BにA）は両方向を見せる。** 作用する側とされる側がある操作は、受け手が対称だと思い込みやすい。①両方向を同じ具体例で並走させる ②向きで変わる物を名指す ③向きで変わらない物も名指す ④実務でどちらを選ぶかを1行。
判断基準＝「受け手が"向きを変えると何が変わり、何が変わらないか"を分けて言えるか」。

**D19 — 新しいやり方を教えるときは、受け手が他所で出会う「旧来の定番」も併記する。** 公式が新方式を推しても、世の中の資料・先輩のメモ・既存の文書は旧方式のままのことが多く、新方式しか知らないと他人の文書が読めない（それ自体が黒箱になる）。①併記は初出の1か所だけ ②新⇔旧の対応表＋なぜ変わったかを1行 ③旧方式が今も通用することを確かめてから書く（→ C1）。
判断基準＝「新方式で学んだ受け手が、旧方式だけで書かれた他人の文書を読み替えられるか」。
※ D4＝別の分野への横の対応／D19＝同じ分野の新旧世代の縦の対応。

**D20 — 「選ばなかった方」の名前が本線に露出したら、その場で一言＋付録で開ける。** 二択の一方を採っても、捨てた側の名前が手順・設定・選択肢の表記に残ることがある（「◯◯しない」オプション等）。「使わないから説明不要」と飛ばすと黒箱になる。①名前が最初に漏れたその場で「一言のたとえ＋なぜ選ばないか」を1行 ②深入りは付録に隔離し（→ A10）、本線からポインタを張る。
判断基準＝「選ばなかった方の名前を見た受け手が"何を・なぜ選ばないか"を1行で言えるか」。

**D21 — 紛らわしい新しい操作は、受け手が既にできる「基本操作の逆向き」として導入する。** 似た新操作どうしを並べて丸暗記させると混ざる。①基準を、受け手が手足のように使える既知の操作に固定する ②新操作を「その逆」として、同じ具体例で前→後・後→前を並べる ③既知の操作が複数の仕事をしているなら、仕事ごとに逆操作を対応づける表を1枚 ④完全な逆が成立する条件も一言。
判断基準＝「受け手が新操作を"知っている◯◯の逆"と1行で言えるか」。

**D22 — 「安全」「〜するだけ」「〜しない」と非破壊性をうたう操作は、作用範囲を「触る／触らない」の対比で開く。** 安心の形容詞は「何が起きないか」を言うが「何に・どこまで作用するか」を言っていない。①触る層と絶対に触らない層の2列表を1枚 ②作用対象を正確に名指す（本体か、その写しか） ③「触らない」側を実際の結果で証明する（→ C1） ④範囲が条件で変わるならそれも ⑤「触る」側も具体例で示す（何が・どこに・どう変わるか）。
判断基準＝「その操作の後、何が変わり何が変わらないかを受け手が2列で言えるか」。

**D23 — 教材だけの"足場"は、①足場だと明示し ②実務の型を1つ添え ③「どれが本物か」を確かめる手段を渡す。** 説明のための入れ物・仮の役名・簡略した環境は、明示しないと実務の型だと誤解される。似た物（箱と本体、写しと原本）が並ぶなら、散文で言うだけでなく受け手自身が判定できる確認手段を渡す。仮の役名には「深い意味はない」と一言。
判断基準＝「受け手が"どれが本物か"を自分で判定でき、"これは足場で実務はこう"を区別できるか」。
※ D6＝やり方が慣用か学習用か／D23＝周辺の足場（環境・配置・命名）が実務か学習用か。

**D24 — 集約・合成した結果の"値"を説明する。** 加重平均・合算・配分のような集約結果は、計算を追えても「で、この数は何？」で止まる。①軸を名指す（何の並びか） ②入力のどれとも一致しない"合成値"だと言う ③各寄与の内訳表を縦に ④なぜ素朴な極値（最大値・どれか1つそのまま）にならないかを言う。＋下流で何になるかを1行。
判断基準＝「受け手が結果の各数を"何の軸で・どの入力がどれだけ効いて・なぜ極値でないか"まで言えるか」。

**D25 — 前段で教えた多段手順を「名前で参照して回す」だけで畳まない。** 新しい入力に対しては中間値が別物になり、しかもその中間値が今段の新しい主張を運んでいることが多い（畳むと発見が消える）。①参照した手順を新しい入力で段ごとに再実行して見せる ②入力が変わった点を明示する ③中間値が今段の主張を運ぶなら必ず開く。
判断基準＝「"前段のアレを回す"の一言で、受け手が中間値を自力で再現する羽目になっていないか」。
※ B28＝値の畳み／D25＝手順の畳み。

**D26 — 同じ物に、段や視点が変わったからといって別の名前を与えない。** 1つの物には「作り方側」と「結果側」の呼び名が自然に付くが、段ごとに使い分けると受け手には別の物が2つあるように見える。①1つの実体に主名を1つ決めて固定 ②別の呼び名を出すなら、その場に「同じ物の別の呼び方」の対応を置き、元の段にも1行の前方参照を置く ③呼び分ける必然性（視点の違い）を言葉にできないなら、呼び名を1つに統一する。
判断基準＝「同じ物の2つの呼び名が、対応づけなしで並んでいないか」。
※ §8 対話3＝1語が2つの物を指す混乱／D26＝1つの物が2つの名を持つ混乱。

### 柱E: 導出を教える（枠でなく論理）

**E1 — 逆算で教える（ゴール → 判定 → 材料 → 表 → 規則）。** 仕組みから積み上げず、ゴールから後ろ向きに。①何を出したい？ → ②それを制御する判定は？ → ③その判定は何で決まる？（材料）→ ④全組み合わせを表に → ⑤**規則・式は最後に表から読み取る**（いきなり式を書かない）。

**E2 — 第一原理で教える（核 → 部品を導出 → 1つずつ）。** E1 と対になる型。その分野の**動かない核心**を最初に1行置き、そこから必要な部品を導出する。核を先に置くと各部品が「核の一部」として意味づく（「なぜこの部品？」に核から答えられる）。

**E3 — 部品は「発明の1問」で必然にする。** 枠（①②③の3つが要る）を名指すだけでは「どう思いつくの？」に答えていない。①**答えの材料を先に固定**する（使えるのはこの2つだけ、等）→ ②各候補に判別の問い（「既存のものから作れる？ 作れない＝消去法でこれを発明」）→ ③形も問いで決める（素朴案が破綻するギャップから）。

**E4 — 条件はまず自然文の一文で。** 「Xになるのは【…】かつ【…】のとき」と日本語で書き、「かつ／または」で切ると各節がそのまま材料になる。**文 → 材料 → 式**の順。

**E5 — 表は「作り方」を見せる。** ①材料を列に → ②全組み合わせを機械的に列挙 → ③各行で「何を出したい？」を決める（**人間が考えるのはここだけ**）→ ④どちらでもよい行をまとめて短くする。「8行 → 3行に減った」までを見せる（完成形の表を突然出さない）。

**E6 — 判定の「向き」を結果に揃える。** 各材料の"真"が結果の方向に働くように揃える（「消した」でなく「未消し」）。否定が散らばったら向きを疑う。

**E7 — 汎用の核と題材固有の肉付けを分ける。** 教材は ①汎用の核（別の例2〜3個も同じ形に収まる）と ②この題材だけの肉付け の2層になりがち。**どちらの層かを明示する**（用途を取り違えさせない）。

**E8 — 「なぜ次の仕組みが要るか」は断言せず、前段で確立した要素から限界を導出する。** 「◯◯は両立しにくい」と抽象で断言すると「なぜ？」で止まる。①前段で受け手が既に持っている要素に立ち返る ②その要素が生む"1つしかない資源"（予算・枠・通り道）を名指す ③複数の役目がその資源を奪い合う衝突を具体1件で見せる（→ B19） ④走っている比喩を持ち越す（新しい比喩を作らない → D15） ⑤解＝資源を増やす、へ橋渡しし、詳細は次節へ。
判断基準＝「"なぜ今の仕組みでは足りないか"を、前段の要素 → 1つしかない資源 → 奪い合い の連鎖として言えるか」。
※ A14＝動機を置く位置／E8＝その動機の中身。

## §4 説明の厚さ（level）

「説明は簡潔に」は**完成した参照文書**の話。学習用の新概念は、逆に厚く。判断軸は §1 のプロファイルだけ。

### 初学者領域の新概念 → 教科書レベルで逐次に

新しい語・記法・手続きには**5点セット**を必ず付ける（未説明をゼロにする）:

1. **分解図** — どの部分が何かを記号で真下に指す

```
  A ── B ──▶ C
  │    │     └ 到達点
  │    └────── 関係の種類
  └─────────── 出発点
```

2. **既知との対応表**（→ D4）
3. **1行1概念の逐次注釈** — 基本的な部分にも一言添える
4. **なぜ ＋ たとえ**（→ D5）
5. **具体値で before → after／状態表**（→ B1, B2）

さらに冒頭に**その回の新概念だけのミニ解説**を置く。一段一概念なので、厚く書くのはその回の新概念に集中し、既出は「前提: 第N回済み」の参照で済ませる。

> 目安: 新概念1つにつき10〜30行使ってよい。
> **失敗は「注釈が多すぎる」ではなく「未説明が残っている」方。**

### 既知領域 → 最小限

知っている物は要点だけ。冗長な注釈は付けない。

### 提示の作法（初学者領域共通）

- **素直な形で書く。** 玄人向けの圧縮された慣用表現を避け、名前のついた要素・明示的な手順で。慣用句は読めない＝理解できない。※言語・道具自体が既知でも、**教えたい対象**の部分には適用する。
- **入れ子を避け、早期脱出でフラットに**（→ A5）。
- **結果の見せ方も教材の一部**（→ C1）。①比較（前 vs 後、方式A vs 方式B）は表に ②注目すべき値・差分は強調 ③結果の直後に「▼ 読み方」を1行添える（**どこを見ればいいかを出力自身が案内する**）。

### 3層の道案内（どの成果物でも）

1. **骨格マップ** — 冒頭に構成一覧（上＝全体像 → 下＝細部のピラミッド）を置き、本文にも対応する区切り見出しを入れる。注釈は局所の説明だけでなく「**全体をナビゲートする地図**」の役割も持つ。
2. **部品ごとの一言** — 主要な部品1つずつに「これは何か」を1行。似た部品が並ぶ場所では、大きな見出しだけでは足りない（見出し＋部品ラベルの2層）。
3. **関連先の所在** — 単体で追えない構成では、冒頭に相手の在り処を1行（「次にどこを開けばいいか」の道標）。**実在を確認してから書く**（古い参照は信頼を壊す）。

末尾に**実際の結果**（→ C1）。

## §5 学習版 → 実運用版（シリーズの締め）

学習版が終わったら、最後に「実運用版の形」を提示する。

| | 学習版 | 実運用版 |
|---|---|---|
| 構成 | 1か所に全部（読みやすさ優先） | 役割ごとに分割（保守性優先） |
| 参照 | 外部の既知資源だけ | 自分の層を相互参照 |
| 目的 | 概念を1か所で理解する | 再利用・変更容易・検証しやすさ |

**分割は「難しい中身が増えた」のではなく、同じ中身を役割ごとに整理し直しただけ**、と必ず言う。

## §6 失敗カタログ（運用）

実際にやった失敗を1〜3行＋ID参照で追記していく索引。詳細ルールは原則側に書き、ここには重複させない。抽象で残る典型パターン:

**柱A**
- 段間で骨組みごと作り直し、ほぼ別物になった → **A2**
- 鍵の1点を他とまとめて入れ、「最初からある呪文」に見せた → **A4**
- 各段の局所差分は出したが、全体の累積を俯瞰させなかった → **A8**
- 「題材が使わない」を理由に、分野の共通語彙を範囲から落とした → **A9**
- 必修と任意を混ぜ、番号が学ぶ順と一致していなかった／外部シリーズの完走を前提にした → **A10**
- 段Nと段N−1で結果がたまたま一致し「同じ＝繰り返し」と誤解させた → **A11**
- 「すべての◯◯に」を自分の狭い定義で絞り、取りこぼしを1つずつ再依頼させた → **A12**
- 部品を個別に教えたが、つながって何をするかの統合を見せなかった → **A13**
- 各段が独立して見え、前段とのつながり（動機）が冒頭に無かった → **A14**
- 段を足すたびに「何番に入れる？」と相談して手を止めさせた → **A15**
- 似た概念をまとめて先に教え、共通部品を最後に回したため実行順とずれた → **A16**
- 変更依頼で下調べと道具づくりに手番を使い、対象を1行も変えずに報告した → **A17**

**柱B**
- 抽象説明だけで、その値を生む具体を1つも示さなかった → **B1**
- 中間物を見せず最終結果だけ出し「前回と同じでは？」と混乱させた → **B7**
- 例の値を境界・既定と紛らわしい値にし「初期値では？」と迷わせた → **B8**
- 新概念を無意味な記号だけで例示した／比喩を出して具体値に着地させなかった → **B9**
- 規則を記号だけ見せ、手で解いた例なしに実物へ進んだ → **B10**
- 多次元の値を1行に平坦化して流した → **B11**
- 代表1件だけ展開して「残りも同様」とし、下流で使う値の出所を消した → **B12 / B18 / B23**
- 対応・由来・流れを散文で説明した → **B13**
- 版の違いを差分記号・一言・履歴見出しで済ませた → **B14**
- 入力で結果が分かれる仕組みを1例だけで見せた → **B15**
- 図の色を閲覧環境任せにし、ある環境で線とラベルが沈んだ → **B16**

## §8 対話時の原則（教材作成ではなく、質問に答えるとき）

**対話1 — 根本原因を最初に、具体的な1つで。** 「これはどこから来たの？」には、それを生んでいる**実際の1か所**を最初に指す。抽象的な流れの説明や、受け手に複数箇所を自力で追わせる説明を前提にしない。

**対話2 — 相手のラベル軸をそのまま採用する。** 相手が使っている呼び名・区切りを尊重する。別の分類を足すなら**違う名前**にして混ぜない。

**対話3 — 多義な語には最初に定義表。** 「どっちの◯◯？」が起きる語は、呼び名・種類・指すもの・具体例の定義表で固定してから話す。

**対話4 — 説明と実物は同じ印で結ぶ。** 説明側で範囲を語るなら、実物側にも同じラベルの範囲マークを入れて対応させる。

分からない所はその場で仕組みから解説し、価値が高ければ文書に残す。

## §9 依頼の仕方（受け手向けメモ）

新しい分野を学ぶときは、この文書を渡して次の3行で足りる:

> 私は **〈分野名〉** を初学者として学びます。この「段階的説明の原則」に従って、
> 番号順の段階的な解説シリーズを作ってください。まず §1 のプロファイルを確認し、
> 設計（範囲・段数・題材）を相談してから作り始めてください。
